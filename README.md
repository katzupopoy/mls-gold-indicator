# Market Lab Syndicate – Gold Indicator (MT5)

The MLS Gold indicator for MetaTrader 5 draws the Market Lab Syndicate session zone map on XAUUSD (gold) charts: resistance and support zones, the pivot, and the daily market insight panel.

## Download

**[⬇ Download the latest version](../../releases/latest)**. Open the link and click `MLS_Gold_Indicator_B49a.zip` under **Assets**.

## ⚠ Browser warning when downloading

Some browsers (Chrome, Edge) may say this file is **"uncommon", "suspicious", "unwanted" or "may be harmful"**. This happens because:

- it is a new file that not many people have downloaded yet, and
- it contains MetaTrader program files (`.ex5`), which browsers don't recognize.

It is **not** a virus. To keep the file:

- **Chrome:** open Downloads, click the warning, then choose **Keep** (or **Download suspicious file**).
- **Edge:** click the **…** next to the download, choose **Keep**, then **Show more** and **Keep anyway**.
- **Windows SmartScreen / antivirus:** choose **More info** and **Keep / Allow**.

Only download from this official page or the Market Lab Syndicate Facebook Page. Never install a copy someone sends you privately.

## What's inside

- `Market_Lab_Syndicate_B49a.ex5`: the chart indicator (goes in `MQL5\Indicators`)
- `Gold_Feed_Service_v1.05.ex5`: the background service that keeps the zones and insight updated (goes in `MQL5\Services`)
- `INSTALL.txt`: step-by-step install guide

## Requirements

MetaTrader 5 on Windows, an internet connection, and an active license (1 PC, one session at a time). After downloading, message the [Market Lab Syndicate Facebook Page](https://www.facebook.com/bikeendingandraffle) to activate your license.
